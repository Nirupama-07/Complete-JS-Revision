A structured JavaScript revision repository covering everything from the fundamentals to advanced concepts through theory, coding exercises, mini-projects, and interview questions.

- Data Types
- Operators
- Type Conversion & Coercion

- Arrow Functions

- Spread & Rest Operators
- Classes

- Modifying objects

- Change content by using DOM

- Events
- addEventListener,removeEventListener

- Event Objects
- DOMContentLoaded,Load
- Scroll
- Event Bubbling
- Event Capturing
- Event Delegation

### 📌 Phase 6 – Asynchronous-JS
- Synchronous vs Asynchronous
- Event Loop
- Callback 
- Promises and its methods
- async/await

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Nirupama-07/Complete-JS-Revision.git
```

Go to the project folder

```bash
cd Complete-JS
```

Install dependencies

```bash
npm install
```

Start Tailwind CSS

```bash
npx @tailwindcss/cli -i input.css -o output.css --watch
```
