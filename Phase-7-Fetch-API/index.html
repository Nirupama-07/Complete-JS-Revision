Javascript Fetch API

Q(1)fetch API?

Answer:Fetch API is a modern js interface used to make http request(such as GET,PUT,POST,Patch and delete) to the server.It allows your application to read and receive data asynchronously without relaoding the webpage.

syntax: fetch(url,options)

url:the endpoint where the request is sent.
e.g fetch("https://jsonplaceholder.typicode.com/users");

options:an object that specifies how the request should be made.
fetch(url, {
  method: "POST",
  headers: {
   "Content-Type": "application/json"
  },
 body: JSON.stringify(data)
});

Q(2)Why fetch() returns a promise?

Answer:fetch() returns a Promise because making a network request is an asynchronous operation. The server may take some time to respond, so JavaScript doesn't block the execution while waiting. Instead, fetch() immediately returns a Promise, which eventually becomes fulfilled when the response is received or rejected if the request fails.
e.g.
fetch("https://jsonplaceholder.typicode.com/users")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.log(error);
 });

Q(4)Why response.json() is used?

Answer:The promise resolves into an response object.The response is still a stream of data not a js object. response.json converts the JSON response body into a JavaScript object/array.

Answer:

    }
    const data=await response.json()

      }
    );
    if (!response.ok) {

Q(9)Give one example of fetch and DOM

Answer:

let btn=document.getElementById("btn")
let usersDiv=document.getElementById("users")
btn.addEventListener('click',async()=>{
  try{
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );
    if (!response.ok) {
      throw new Error("Something went wrong");
    }
    const users = await response.json();
    usersDiv.innerHTML = "";
    users.forEach(user => {
      const p = document.createElement("p");
      p.textContent = user.name;
      usersDiv.appendChild(p);
    });
  }catch(error){
    console.log(error);
  }
})

Q(12)What is localstorage?

localStorage is a browser storage mechanism that stores data as key-value pairs with no expiration time. The data remains available even after the browser is closed and reopened, until it is explicitly removed.

Methods are:
Set Item: localstorage.setItem("name","Nirupama") Get Item:const name= localstorage.getItem("name")
console.log(name)
Remove one item:localstorage.removeItem("name")
clear:localstorage.clear()
e.g.
const user={
name:"Nirupama",
age:22
} localstorage.setItem("user",JSON.stringify(user))
retrieve:-
const data=JSON.parse(localstorage.getItem("user"))
console.log(data.name)

Q(14)What are cookies?

Cookies are small pieces of data stored by the browser that are automatically sent to the server with every HTTP request to the same domain.
