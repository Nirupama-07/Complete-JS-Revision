Q(1)What is Event?

Answer:JS events are actions or occurences that are happen in the browser. They can be triggered by various user interaction or by the browser itself.

Actions like:

  • User clicking on a button
  • User submitting a form
  • User types an input
  • User scrolls the page
e.g. const btn = document.getElementById("btn");
btn.addEventListener("click", function () {
  alert("Button clicked");
});

Q(2)What is addEventListener()?

Answer:addEventListener() is a function which listens for events(such as click,mouseover,keydown,etc.) on that elements and executes a function when the event occurs.

e.g. const btn = document.getElementById("btn");
btn.addEventListener("click", function () {
  alert("Button clicked");
});

Q(3)What is removeEventListener()?

Answer:It is a built in function that is used to remove an event handler that was previously added using addEventListener().

e.g.
const btn1=document.getElementById("btn1")
const btn2=document.getElementById("btn2")
function sayHi(){
  alert("Hi Welcome")
}
btn1.addEventListener('click',sayHi)
btn2.addEventListener('click',()=>{
  btn1.removeEventListener('click',sayHi)
})

Q(4)What is click Event?

Answer:It gets triggered when an element is clicked.

It can be click or dblclick:

const btn3=document.getElementById("btn3")
const btn4=document.getElementById("btn4")
btn3.addEventListener('click',()=>{
  alert("Works on click")
})
btn4.addEventListener('dblclick',()=>{
  alert("Works on double click")
})

Q(5)What are some mouseEvents?

Answer:Some of the mouse events are:

mouseOver():gets triggered when a mouse pointer moves over it.
mouseout():gets triggered when a mouse pointer moves out of the specified element.

const heading1=document.getElementById("heading1")
heading1.addEventListener('mouseover',()=>{
  heading1.style.backgroundColor="pink"
})
heading1.addEventListener('mouseout',()=>{
  heading1.style.backgroundColor="red"
})

Q(6)What are some keyEvents?

Answer:Some of the key events are:

keydown():gets triggered when a key is pressed.
keyup():gets triggered when a key is released.

text.addEventListener('keydown',(e)=>{
  console.log(e.target.value)
})
text.addEventListener('keyup',(e)=>{
  console.log(e.target.value)
})

Q(7)What are some formEvents?

Answer:Some of the key events are:

submit():gets triggered when form submit button is clicked.
input():gets triggered everytime the value changes

change():gets triggered everytime the value changes and looses focus(e.g. dropdown,checkboxes,date pickers)

focus():when an input gets focus

blur():when an input looses focus

reset():when the form is reset

invalid():when a form field fails html validation

const form=document.getElementById("form")
form.addEventListener('submit',(event)=>{
  event.preventDefault()
  console.log("Form submitted")
})
form.addEventListener('reset',(event)=>{
  console.log("Form reset")
})
const name=document.getElementById("name")
name.addEventListener('input',()=>{
  console.log(name.value)
})
name.addEventListener('focus',()=>{
  console.log("input focused")
})
name.addEventListener('blur',()=>{
  console.log("input loose focus")
})
const subject=document.getElementById("subject")
subject.addEventListener('change',()=>{
  console.log(subject.value)
})
const email=document.getElementById("email")
email.addEventListener('invalid',()=>{
  console.log("Email is not valid")
})

Q(8)What are event objects?

Answer:When an event occurs javascript automatically creates an object called event.

Some useful properties:
event.target(): which element triggered the event
event.type(): return the type of event which get triggered
event.preventDefault(): stop the browsers default behaviour
event.stopPropagation():stop event bubbling
event.key():returns the pressed key
event.code():returns the physical key on the board
event.clientX():returns the mouse X coordinate inside the browser window
event.clientY():returns the mouse Y coordinate inside the browser window

Q(9)What is DOMContentLoaded?

Answer:DOMContentLoaded fired when the html content has been completely loaded and parsed.

It does not wait for:

  • Images
  • Videos
  • CSS Background images
  • Large files

document.addEventListener("DOMContentLoaded", () => {
  const btn = document.getElementById("btn");
  console.log(btn);
});

Q(10)What is load?

Answer:The load event occurs when the entire page has finished loading.

This includes:

  • HTML
  • Images
  • Videos
  • CSS Background images
  • Large files
  • Fonts
  • Scripts
  • Iframes

window.addEventListener("load", () => {   console.log("Everything Loaded"); });

Q(11)What is scroll?

window.addEventListener("scroll", () => {   console.log("Scrolling....."); });


Sticky navbar

window.addEventListener("scroll", () => {

}

Show back to top

if(window.scrollY > 500){

}

Q(12)What is Event Bubbling?

Answer:It is a mechanism where an event gets triggered on a child element it propagates upward through its ancestors in the DOM. It can be stop by event.stopPropagation()

parent.addEventListener("click", () => {
  console.log("Parent");
});
child.addEventListener("click", () => {
  console.log("Child");
});

Q(13)What is Event Capturing?

Answer:It is a mechanism where an event gets triggered when it moves from parent to child before bubbling.

parent.addEventListener("click", () => {
  console.log("Parent");
},true);
child.addEventListener("click", () => {
  console.log("Child");
});

Q(14)What is Event Delegation?

Answer:It is a mechanism where instead of adding listeners to every child element add one listener to the parent.

const list = document.getElementById("list");
list.addEventListener("click", function(event){
  console.log(event.target.textContent);
});
